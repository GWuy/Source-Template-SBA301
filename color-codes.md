## 🔄 Cách đổi màu trong AppLayout.css

> **Bước 1:** Chọn màu ưng ý từ bảng trên
> **Bước 2:** Tìm và thay trong `AppLayout.css`

### Ví dụ: Đổi header từ Navy → Teal

```css
/* TÌM: */
.app-header {
  background-color: #2c3e6b;
}

/* THAY: */
.app-header {
  background-color: #008080;
}
```

### Ví dụ: Đổi toàn bộ theme (Find & Replace)

```
Tìm:     #2c3e6b
Thay:    #008080
→ Đổi tất cả (Replace All)
```

> **⚠️ Lưu ý:** Khi đổi `#2c3e6b` (navy), các vị trí sau sẽ đổi cùng lúc:
>
> - Header background
> - Table header background
> - Page title color
> - Filter button
> - Save button
> - View link color
> - Pagination active
>
> → Đây là **thiết kế có chủ đích** — giữ màu nhất quán (consistent theme).

## 📋 Bảng Category Badge — Thêm/Đổi Màu

Trong `EntityList.jsx` và `DetailEntity.jsx`, đổi object `CATEGORY_COLORS`:

```js
const CATEGORY_COLORS = {
  // ← Đổi key theo category thực tế
  IT: "#2980b9", // Xanh dương
  HR: "#8e44ad", // Tím
  Finance: "#27ae60", // Xanh lá
  Marketing: "#e67e22", // Cam
  Sales: "#c0392b", // Đỏ
  Engineering: "#2c3e50", // Đen xanh
  Design: "#e91e63", // Hồng
  Legal: "#795548", // Nâu
  Admin: "#607d8b", // Xám xanh
  Support: "#00bcd4", // Cyan
  Research: "#9c27b0", // Tím đậm
  Operations: "#ff9800", // Cam sáng
  Management: "#3f51b5", // Indigo
  QA: "#009688", // Teal
  Training: "#cddc39", // Lime (nên dùng text đen)
};
```

> **💡 Tip:** Nếu không biết category name trước → dùng default color `#6c757d` (xám).
